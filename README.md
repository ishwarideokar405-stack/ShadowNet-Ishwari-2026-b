
# ShadowNet-Ishwari-2026-b

## Offline Emergency Communication

ShadowNet is a prototype emergency communication application developed for **Hack Devengers 2.0**.

### Problem Statement
During disasters, internet and mobile networks may fail, making it difficult to contact emergency services.

### Proposed Solution
ShadowNet provides:
- 🚨 SOS Button
- 📶 Online/Offline Detection
- 💬 Offline Chat (Prototype)
- 🗺️ Safe Route Information
- 📞 Emergency Contacts
